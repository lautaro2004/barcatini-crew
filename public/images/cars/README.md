# Fotos de invitados

- `guest-0X.webp` — vehículo recortado (PNG/WebP con transparencia). Es lo que usa la escena 3D.
- `originals/` — flyers originales completos (fuente para volver a recortar).

Para agregar un invitado: poné `guest-06.webp` acá y sumá un objeto en `src/data/guests.ts`.
Recorte: el vehículo completo, sin fondo, sin reflejos del piso, sin texto. No estirar ni cambiar colores.
